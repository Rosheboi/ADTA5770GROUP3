# ADTA5770GROUP3
Project for ADTA 5770 Group 3: Website to display contaminated PDFS

## Website
The website displays 2 tables: one with a list of medical documents and another one with a list of general(Industrial Engineering) documents.
Each row has the title of the document and a button which has a link that retrives the link for that specific title.
Inside each pdf contains an article that has contaminates in there: meaning there are deliberate typos and mistakes in there.
